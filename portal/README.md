# Редактор заключений экспертизы

React-приложение редактирует XML заключения 01.04 по структуре XSD. Для заключений 01.03 доступны XML, проверка, преобразование и выгрузка совместимого результата. Исходный файл можно скачать отдельно, а замечания к преобразованию отображаются до принятия результата.

Проверка и формирование HTML-предпросмотра выполняются локальным сервисом ProjectDocumentation. Предпросмотр использует XSL соответствующей версии. Черновики сохраняются в этом браузере по явной команде. В режиме WinForms документ сохраняет десктопное приложение через WebView2.

## Запуск разработки

Из корня репозитория установите зависимости Python и запустите сервис.

~~~powershell
python -m pip install -r schema_engine/requirements.txt
python -m schema_engine --port 8765
~~~

В другом окне выполните из корня репозитория.

~~~powershell
Set-Location portal
npm ci
npm run dev
~~~

Откройте http://127.0.0.1:5173. Vite пересылает запросы к схеме и документам на порт 8765.

## Сборка

В каталоге portal выполните npm ci и npm run build. Готовая сборка находится в portal/dist. Сервис раздаёт её на http://127.0.0.1:8765 после запуска из корня репозитория.
