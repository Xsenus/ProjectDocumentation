# Редактор документов экспертизы

React-приложение редактирует заключения 01.04 и пояснительные записки 01.07 по структуре XSD. При импорте вид документа определяется по корневому элементу XML. Заключения 01.00, 01.02 и 01.03 и записки 01.03 и 01.05 можно преобразовать в актуальную версию. Совместимая выгрузка доступна для заключения 01.03 и записки 01.05. Исходный файл можно скачать отдельно, а замечания к преобразованию отображаются до принятия результата.

Проверка и формирование HTML-предпросмотра выполняются локальным сервисом ProjectDocumentation. Для заключений 01.00 и 01.02 доступны проверка по официальной XSD и преобразование из режима XML. Предпросмотр по XSL доступен для заключений 01.03 и 01.04 и записок 01.05 и 01.07. Черновики сохраняются в этом браузере по явной команде.

## Запуск разработки

Из корня репозитория установите зависимости Python и запустите сервис.

~~~powershell
python -m pip install -r schema_engine/requirements.txt
python -m schema_engine --port 8765
~~~

В другом окне выполните из корня репозитория.

~~~powershell
Set-Location portal
npm ci
npm run dev
~~~

Откройте http://127.0.0.1:5173. Vite пересылает запросы к схеме и документам на порт 8765.

## Сборка

В каталоге portal выполните npm ci и npm run build. Готовая сборка находится в portal/dist. Сервис раздаёт её на http://127.0.0.1:8765 после запуска из корня репозитория.
