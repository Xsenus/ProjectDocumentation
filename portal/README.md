# Веб-редактор ProjectDocumentation

В полном комплекте запустите `Start-Portal.cmd`. Он открывает `http://127.0.0.1:8765` в браузере. Если нужен другой порт, запустите `ProjectDocumentation.Schema.exe --port 8766 --open-browser` в каталоге комплекта. Локальная служба выполняет проверку XSD, преобразование и предпросмотр XSL. Оставьте её окно открытым во время работы.

Откройте существующий XML или создайте документ. Заполните форму по разделам, нажмите «Проверить XML», проверьте предпросмотр и выгрузите проверенный файл. Для незавершённой работы используйте «Сохранить в браузере» или «Скачать черновик». Импортированный оригинал доступен через «Скачать исходный XML». Черновики зависят от профиля браузера и адреса портала.

В поле «Найти поле» введите название, имя XML-элемента или путь. Выберите результат, чтобы перейти к полю. Если нужная ветка ещё отсутствует, курсор перейдёт к кнопке её добавления или списку вариантов. После проверки путь из списка ошибок ведёт к полю, где показано пояснение.

В пояснительных записках 01.05 и 01.07 таблицы в текстовых блоках редактируются по строкам и ячейкам. Можно добавлять строки заголовка и данных, менять их порядок и выбирать выравнивание каждой ячейки. Общий столбец добавляется во все строки с одинаковым числом ячеек. В таблице с рядами разной длины можно добавить ячейку к отдельной строке.

«Проверить XML» проверяет документ локально по XSD или схеме совместимости. В разделе «Проверка и реестр» можно открыть сервис проверки XML Главгосэкспертизы и поиск заключений в ЕГРЗ. Ссылки открывают официальные сайты в отдельной вкладке.

| Документ | Редактирование в форме | Преобразование | Предпросмотр XSL |
|---|---|---|---|
| Заключение | 01.04 | 01.00, 01.02 и 01.03 → 01.04, 01.04 → 01.03 | 01.03 и 01.04 |
| Пояснительная записка | 01.05 и 01.07 | 01.03 и 01.05 → 01.07, 01.07 → 01.05 | 01.05 и 01.07 |

## Запуск разработки

В корне репозитория установите зависимости Python и запустите локальную службу.

```powershell
python -m pip install -r schema_engine/requirements.txt
python -m schema_engine --port 8765
```

Во втором окне из корня репозитория запустите Vite.

```powershell
Set-Location portal
npm ci
npm run dev
```

Откройте `http://127.0.0.1:5173`. Vite пересылает запросы к XML-службе на порт 8765.

## Сборка

В каталоге `portal` выполните `npm ci` и `npm run build`. Готовая сборка появится в `portal/dist`. Запустите XML-службу из корня репозитория, чтобы открыть собранный портал на её адресе. Для полного Windows-комплекта используйте `tools/Build-Release.ps1`.
